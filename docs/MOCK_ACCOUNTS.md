# Mock 测试账号一览（仅手机号 + 说明）

> **生效前提**：在开发者工具 Storage 设置 `zhixing_run_mock_seed` = `1` 后重启，执行 `mockDataSeed.js` 的 `runFullMockSeed()`。  
> **档案来源**：`TEST_PROFILES` 中号码先写入 `zhixing_user_profiles`；其余号码用「同一手机号下 **createdAt 最新** 一条入驻申请」定 `onboardingStatus` 与 `role`（`writeProfiles` / `ensureStatusFromApplications` 同逻辑）。`TEST_PROFILES` 与申请队列**同号**时以 **TEST_PROFILES 优先**，不再被申请表覆盖。  
> **不列手机号的数据**：`MOCK_HOURS` 认定义务时长、`MOCK_UNBIND` 解绑、结对 `setActivePair`、`match/center` 的 `rawList` 等页面临时演示，见 [MOCK_DATA.md](./MOCK_DATA.md)。

## 与「几个学生」相关的再次说明

| 类型 | 含义（本工程 Mock） |
|------|---------------------|
| **乡村学员账号** | 1 个手机号 = **1 名学生用户**；不存在「一账号管多名学生」。 |
| **受援方二级 13800138020** | **多个「学生入驻申请单」**会路由到其区域待办，条数 = seed 里多笔，非「你名下 N 个在读生」固定名单。 |
| **支教方二级 13800138010** | 管的是**志愿者/教师**侧审核，不是「X 个学员」。 |
| **受援方老师聊天** | 仅 `reviewedByL2=本号` 的**已通过**学生有会话，见 `getPairedListForRecipientL2`；**无**代操作学员列表。 |

更细的申请 ID、学校、驳回理由、时间线以源码 `miniprogram/utils/mockDataSeed.js` 为准。
