# 本地联调种子数据说明

本文档对应 `docs/seed_local_debug.sql`，用于说明数据矩阵、关键场景与使用方式。

## 1. 适用范围

- **数据库**：`aid_education_platform`
- **建表脚本**：`zhixingtongyi-zyh/design/init.sql` 或 `zhixingtongyi-lxy/design/init.sql`（两者结构兼容）
- **主键号段**：`9001 ~ 9099`，所有 seed 数据均在该区间，避免与真实业务数据冲突
- **可重复执行**：脚本开头按子表→父表顺序清理本号段，可反复 `SOURCE`

## 2. 使用方式

```sql
-- 假设已经按 init.sql 建过表
SOURCE d:/homework/WeChatProjects/zhixingtongyi/docs/seed_local_debug.sql;
```

或在命令行：

```bash
mysql -uroot -p aid_education_platform < docs/seed_local_debug.sql
```

- 参与者表覆盖 5 个结对：9001、9004、9005（含 `left_time`）、9007、9009、9006

  - `pair 9001`：函数复习、作业答疑、图片白板、语音提问

## 15. 字段兼容性说明

- 同时兼容 `zhixingtongyi-lxy` 与 `zhixingtongyi-zyh` 的 `init.sql`
- `chat_message` 满足 `fk_chat_sender_participant` 复合外键：每条消息发送者都已在 `chat_participant` 中存在
- `volunteer_record.meeting_id` 同时覆盖了「有 meeting」与「无 meeting」两类
- `match_pair` 中的解绑相关字段（`unbind_admin_id`、`unbind_reject_by` 等）外键均指向已存在用户
